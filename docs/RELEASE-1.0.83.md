# 1.0.83 — 默认材质包单项启停

2026-09-16 20:55

默认配置的每个材质包增加独立开关和已启用／未启用文字。开关状态持久保存，重新导入相同文件或调整顺序不会重置状态；旧配置和新导入文件默认启用。

开启材质包总同步时，下次启动只复制和启用开启的默认材质包，取消关闭项的默认选择和不兼容确认记录，保留原 ZIP、实例内已复制文件及其他材质包。重新开启按原列表顺序应用。总同步关闭时沿用原行为，不改动实例。

验证：472 项自动化测试、类型检查、许可检查及生产构建通过；覆盖现代和旧版游戏、全关闭、重新启用、首次不复制禁用项、重复导入、旧配置迁移和错误参数。实际 Windows 成品验证独立开关、页面重新加载后的持久状态、另一项不受影响、重新启用和窄窗口布局。测试使用独立配置与模拟材质包，未改动用户默认配置或运行中的游戏。
