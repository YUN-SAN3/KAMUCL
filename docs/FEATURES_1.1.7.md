# KAMUCL 1.1.7

## 皮肤绘制

皮肤页的绘制窗口包含启动器内调色板，可拖动饱和度/明度平面和色相滑条，
或输入 HEX、RGB、HSV。吸色同步调色板，基础层保持不透明，外层可调整透明度。
自定义色板、最近实际绘制的颜色与当前颜色保存在本地设置中。
调色本身不会修改皮肤，也不进入皮肤撤销历史。保存 PNG 与账号上传沿用现有流程。

## 顶栏七人彩蛋

点击左上头像，在原顶栏中央展开七位大头方块 Minecraft 小人，关闭后恢复。
人物身份仍为 q3、qiqi、碧月狐、红叔、卡慕、米洛、幕川北；采用单个 WebGL 场景，
依据用户提供的 MC 正背面截图重建像素纹理，移除披风。截图无法恢复被遮挡的原始像素，
这些位置按角色服装风格补全，并非原始皮肤逐字节复刻。

鼠标快速横扫可依次拍打经过的臀部区域，停留不连续触发，离开再进入可以重复拍打。
各人物独立回弹，停止移动后按次数稳定排序；静止鼠标不会因排序产生拍打。
点击和键盘均可拍打，累计次数保留在本地。原创合成拍打声默认开启，可静音及调整音量。
音效不包含下载的第三方录音。减少动态效果模式保留功能，窗口隐藏暂停动画及音频。

## 首页启动卡

内置图片替换为用户提供的七张新图，发布资源进行无损压缩，像素内容不变。
内置与自定义图片共用一个可勾选、排序、调整时长的轮播列表，实例专属图片优先。
关闭默认内置图片或取消单图参与，只改变选择，不删除自定义文件。
全局轮播全部关闭且无实例专属图片时显示主题底色；零图、单图不运行轮播计时器。
主题导入/导出保留选择和顺序，受管自定义图片在导入时重新映射引用。

新图为：Minecraft活塞压扁大冒险、暮色村庄酿药师、熔岩悬崖上的失控大炮、
沙漠仙人掌飞跃大作战、像素农夫与肥料伙伴、月夜篝火下的方块森林营地、方块世界的日落奇遇。

## 社区收藏

Modrinth 和 CurseForge 的 Mod 搜索结果卡片底栏直接提供收藏星标。
收藏与详情、本地管理、安装收藏模组入口共享状态，网络或保存失败显示错误并恢复状态。
资源包、光影包与整合包不提供 Mod 收藏按钮。
