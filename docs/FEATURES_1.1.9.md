# KAMUCL 1.1.9

皮肤编辑器按本轮参考布局采用单个左侧绘制工具栏，中间模型与视角/部位控制，右侧文件、模型、图层和颜色面板。标题、关闭与底部保存/上传固定。缩放、灯光与扩大预览只改变视图，不改变 PNG 文档。原有中键/Alt+左键旋转、左键绘制、撤销、透明层、色板持久化及未保存关闭状态机继续沿用。

全局选择复选框保留原生 input、键盘、checked/indeterminate 与 change 事件；仅替换主题外观。启用开关仍为开关。游戏安装弹窗使用加载器图标卡、版本及附加模组选项卡，继续按当前版本/加载器检查收藏模组，失败或不兼容项不能勾选安装。

卡慕位于原 LOGO 头像位置，不替换顶栏问候。保留大头短身方块比例，白色猪头套、青色上衣、棕色手臂、紫色裤子和灰鞋按本轮附件重绘，背部无披风。附件为渲染参考，隐藏像素不能视为原始皮肤逐点复原。另六人不再加载或互动，其历史计数仍保留。

首次激活不计数。真实用户激活时用一次50毫秒数字零信号准备现有音频输出图，独立于掌击样本/计数/voices；隐藏或释放及时停止并断开。这是初始化行为调整，不预先宣称已证明冷态暂停的单一因果；原生冷LOGO完整过渡与首十击另行复验。点击/Enter/Space 接受一次动作，经转身、手掌接触、音效和手印后回正；长按键重复被忽略，连续动作排队上限32。手印不修改皮肤。关闭处理已接受动作和幂等保存；隐藏暂停，恢复继续，关闭释放资源。新界面重置只清空卡慕，旧 IPC 调用与旧计数格式仍兼容。

原生复评发现晚帧会追赶多个拍打周期并压缩音效。可见动画现限制单次活动时钟推进为50毫秒，遇宿主停顿顺延动作，每次接受都保留独立掌击呈现；隐藏关闭使用原有不受限的计数排空模式。软件渲染互动期间暂时让出网页背景模糊，关闭恢复，主题颜色、透明度和原生系统材质保持。小人和反馈仅在本地合成层更新，反馈定位使用 transform，并跳过数值相同的样式写入；软件光栅化逐字节比较 RGBA，仅实际改变像素时上传 Canvas，不量化姿态、不删不同像素帧。原始低帧率和活动停顿记录保留，新的呈现规则不将其改写为通过。

## 导入接口与兼容

新增 `import:probe(inputPath)` 返回 `{kind:'modpack',info}`、`{kind:'world',info}`、`{kind:'mod'}` 或 `{kind:'unsupported',message}`；拖入单文件和顶部选择文件共用。根目录 Modrinth/CurseForge 清单、现有完整客户端与嵌套 mrpack 识别优先于包内存档。检测到清单但损坏时明确报错，不降级成世界导入。普通存档 ZIP/文件夹和模组 JAR 保留原流程。

PCL 导出的用户样例本身是标准 Modrinth 包，问题为原入口先递归检测 level.dat。清单含46模组、2材质包、2光影包，overrides再含2材质包和1存档。完整安装预期46/4/2/1，Minecraft1.20.1及Forge47.4.23。继续使用已有 HTTPS、多来源、哈希、路径安全、事务备份及回滚，不替换用户文件版本。此前误导入的实例不会自动删除。

- `npm test`：包含小型公开合成包的导入分类，以及互动时间线、幂等持久化、编辑器关闭和手势回归。
- `npx tsc --noEmit`、`npm run build`、`npm run license:check`。
- `scripts/verify-ui-refinement.cjs`：隔离用户目录的成品 GUI 验收；新导入模块 `import119`，选择/安装模块 `selection119`，皮肤模块 `skin118` / `palette`，单人模块 `header`。
- `node scripts/verify-pcl-import-119.cjs <private-export.zip>`：真实安装和所属游戏窗口验证，仅写入 ignored out，不将用户存档纳入公开交付。

最终结果、截图/录屏出处、历史失败和未覆盖项记录在本版本发行文档与交接状态中。夹具平台响应不等同真实在线服务，数值音频检查不等同人工听感。
