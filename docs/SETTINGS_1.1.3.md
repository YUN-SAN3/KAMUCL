# KAMUCL 1.1.3 — 设置分类与紧凑布局

## 需求落实

- 启动器设置：外观 → 行为与登录 → 下载 → 功能与插件 → 关于与更新。
- 游戏设置：运行环境 → 游戏窗口 → 目录与隔离。
- 安装目录、默认隔离属于游戏设置；下载并发、镜像和 API Key 属于启动器下载设置；登录代理与启动后关闭属于启动器行为。
- 两级导航保持可见，搜索跨分类定位，结果显示所属范围，保留键盘焦点、分类滚动位置和范围内最近分类。兼容原来的分类标识。
- 主题以小型横向选项展示；减少动态效果使用紧凑开关行；背景、首页图片、Java 管理与 JVM 参数按需展开。
- 内存与 Java 在宽窗口分栏、窄窗口纵向排列；功能开关两列自适应；限制图片预览与长 Java/轮播列表的默认占用。
- 搜索只展开目标及其祖先，不展开整个区域下的所有高级内容。
- 未修改设置存储结构、默认值、启动、下载或安装业务；没有移除已有设置。主题颜色仍使用现有变量。

## 验证

- 完整自动测试 527 项通过；生产构建、许可证检查通过。
- 独立 Electron 临时配置下验证全部 16 个设置搜索目标、范围切换、滚动恢复、旧配置、减少动态效果和键盘焦点。
- 界面检查覆盖黑紫、白蓝、自定义配色；窗口 960×620、1280×900/125%、1440×960/150%、980×720/150% 和最大化。
- 同一界面验证器检查 13 个主要页面、弹窗、筛选竞争、空/失败状态、长名称及模拟运行状态；固定输入仅存在于隔离测试进程。
- Windows 成品启动与哈希验证报告见 out/windows-package-1.1.3.json；界面报告见 out/ui-refinement-*.json。
- 截图保存在 release/ui-refinement-{transparent,blue-white,custom}/，重点为 settings-launcher-compact.png、settings-game-runtime.png、settings-game-directories.png 与 settings-960-1.png。

本次未以真实账户启动游戏或连接外部联机服务；没有结束用户游戏。界面缩放使用 Electron 缩放因子，未修改操作系统的全局 DPI。
