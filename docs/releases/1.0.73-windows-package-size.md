# 1.0.73 Windows 包体积优化

Windows 保留 Electron 44.3.0。现有毛玻璃修复依赖这一运行内核；内核可执行文件约 246 MB，是下载包的主要体积来源。

| 项目 | 1.0.72 | 1.0.73 | 缩减 |
| --- | ---: | ---: | ---: |
| 便携 EXE | 93,598,047 字节 | 93,255,054 字节 | 0.37% |
| 默认 Windows ZIP | 143,278,986 字节 | 93,283,672 字节 | 34.9% |
| 应用 ASAR | 6,823,530 字节 | 5,859,265 字节 | 14.1% |

ZIP 的主要收益来自分发结构调整。EXE 本身此前已采用高压缩率，本次只进一步减少约 0.34 MB。

## 分发方式

- `KAMUCL-1.0.73.exe`：推荐直接下载，完整离线便携包。
- `KAMUCL-1.0.73-windows-x64.zip`：标准 ZIP Store/Deflate，内含与上面逐字节一致的便携 EXE、使用说明和离线许可。完整解压后运行其中的 EXE；首次在旁边展开 `KAMUCL-runtime`，随后复用缓存，也能使用便携自更新。
- `KAMUCL-1.0.73-windows-x64-unpacked.zip`：保留原先直接展开运行组件的兼容方式，供 NSIS 自解压无法运行的机器使用。文件更大，完整解压后运行 `KAMUCL.exe`。

紧凑 ZIP 使用已有的 7z 固实压缩成果，免去传统 ZIP 对内核的独立 Deflate 压缩。优化的是下载体积；首次展开后的内核仍占用磁盘，不能把 ZIP 的节省比例当作运行目录或内存缩减比例。

## 构建

`npm run dist:win` 生成 EXE 和上述两个 ZIP；`dist` 与 `dist:all` 复用此入口。常规构建使用 electron-builder 的已校验 Electron 下载；本地已有同版 Electron 时可给 builder 传入 `--config.electronDist=node_modules/electron/dist`，避免重复下载。

Windows 文件白名单明确包含应用输出、生产依赖和许可，排除 Koffi 的开发文档、C/C++ 基础源码、vendor 头文件、编译脚本，以及 Undici 开发文档。平台级 `files` 配置需要完整正向白名单：只有否定模式会让 electron-builder 加入默认 `**/*`，误收工作区。`afterPack` 检查目录范围和 16 MiB ASAR 上限，在压缩前拒绝意外膨胀；未来确需增加资产时应先审查再调整阈值。

便携压缩提高 LZMA2 匹配长度到 273，继续使用 128 MiB 字典和原有解码器。完整 Electron DLL、GPU 回退、媒体、语言、图片和许可保留。未采用内核降级、可执行文件加壳或首次联网补下载组件。

## 验证方式

- TypeScript、生产构建、19 项便携/窗口/更新相关测试。
- `scripts/verify-windows-package.cjs` 用 Windows 自带 tar 解压紧凑 ZIP，检查 EXE 字节相同；分别验证中文空格路径冷/缓存启动，逐文件核对运行目录 SHA256，以及兼容 ZIP 的全部文件。与 1.0.72 核对 Electron 的 GPU、媒体、语言及其他未改变的运行资源。
- `scripts/verify-packaged-windows-ui.cjs` 用同版 Electron 测试运行器加载最终 ASAR、preload、renderer 和原生依赖，隔离设置/游戏目录并隐藏测试窗口，检查首页、版本、图片、WebGL 皮肤、真实设置 IPC、Koffi 和打包后台扫描线程。它不是 Minecraft 游戏启动测试。
- `scripts/pack-source.cjs` 提供源码及逐文件哈希。发布脚本上传 EXE、两个 ZIP、源码 ZIP 和 SHA256SUMS.txt，核对远端附件大小与 digest 后再公开草稿 Release。

证据：`out/windows-package-1.0.73.json`、`out/windows-ui-1.0.73.json`、`out/tests-portable-1073.log`、`out/build-1073-final.log`、`out/package-1073-final.log`。
