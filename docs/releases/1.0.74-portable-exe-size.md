# 1.0.74 便携 EXE 体积优化

本批直接缩小便携 EXE 内部的运行负载，不只是调整 ZIP 的包装方式。Windows 仍使用 Electron 44.3.0，Mac 的 Electron 33.4.11 与图形配置不变。

| 项目 | 1.0.73 | 1.0.74 | 减少 |
| --- | ---: | ---: | ---: |
| 便携 EXE | 93,255,054 字节 | 87,105,169 字节 | 6,149,885 字节，6.59% |
| 默认 Windows ZIP | 93,283,672 字节 | 87,133,787 字节 | 6,149,885 字节，6.59% |
| 展开后的运行文件总和 | 342,854,384 字节 | 315,600,613 字节 | 27,253,771 字节，7.95% |

MB 按 1,000,000 字节计：便携 EXE 由 93.26 MB 降到 87.11 MB。若资源管理器按 MiB 显示，则由约 88.94 降到 83.07。运行文件总和不含文件系统簇、便携缓存标记、游戏或用户数据，不等于内存占用。

## 精简范围与兼容边界

Windows `afterPack` 只移除两份可选的 Dawn/D3D12 DXC 编译组件：

- `dxcompiler.dll`：25,744,896 字节。
- `dxil.dll`：1,509,760 字节。

构建钩子限定 Electron 44.3.0 / Windows x64，逐一核对原始 SHA256、普通文件属性和输出路径；全部候选校验成功后才删除。遇到新版内核、其他架构或 DLL 内容变化时停止构建，要求重新审查，不静默沿用裁剪规则。

当前首页与皮肤查看器使用 Three.js WebGLRenderer，不使用 WebGPU。缺少 DXC 的 Windows 运行环境在 Electron ready 前关闭 `WebGPUService` 和实验性 Skia Graphite，避免选用依赖已移除组件的后端；保留现有 ANGLE/WebGL、GPU 合成及其图形组件。完整开发运行环境有 DXC 时不增加这些开关。

这不是保持全部 Chromium API 的无差别压缩：Windows 精简包不再提供 WebGPU，未来如果新增依赖 WebGPU/Graphite 的功能或插件，必须重新引入编译组件并复验。现有启动器功能不依赖这些 API。

保留 Electron 主程序、`d3dcompiler_47.dll`、SwiftShader/Vulkan、FFmpeg、语言、资源与许可文件，没有关闭 GPU 加速、降级内核、给 EXE 加壳或改成首次联网补下载。离线使用仍不需要下载额外启动器组件；Minecraft/Java 本身的下载行为未改动。

上游依据：Dawn 的 [D3D12 编译器加载实现](https://dawn.googlesource.com/dawn/+/refs/heads/chromium/7546/src/dawn/native/d3d12/PlatformFunctionsD3D12.cpp)；Chromium 的 [WebGPU 与 Graphite 特性开关及禁用优先级](https://chromium.googlesource.com/chromium/src/+/4fa6513a781a593cd2cd3851586bb75368a73bd4/gpu/config/gpu_finch_features.cc)。裁剪决定同时以本次固定版本的实际运行验证为依据，不推断其他版本必然兼容。

## 验证

- `npm test`：431 项全部通过；包括新增的图形开关、原始 DLL 校验、拒绝错误架构/版本/源码路径、失败时不部分删除以及只移除指定两份 DLL 的测试。
- `npx tsc --noEmit`、生产构建与便携打包通过。
- `node scripts/verify-compact-windows-ui.cjs --presentation`：使用最终裁剪运行目录的独立副本，加载最终 ASAR，隔离设置与游戏目录。首页、版本、本地图片、设置 IPC、打包的 Koffi 原生调用及后台 mod 扫描通过。
- 同一最终运行包分别验证 NVIDIA RTX 5080 / ANGLE D3D11 硬件 WebGL，以及测试专用开关强制的 SwiftShader 软件 WebGL；两者皮肤渲染成功，确认 WebGPU 不再提供 adapter、Graphite 已禁用。生产代码没有强制软件渲染或打开不安全的软件渲染开关。
- 普通窗口、接近最大化和最大化：稳定采样期间背景像素无变化、无闲置 resize 回环、WebGL context 未丢失、动画持续；最终采样分别 955 / 961 / 960 帧（每组约 4 秒）。一次受窗口事件干扰的最大化采样被标记并重测，不计作稳定结果。
- `scripts/verify-windows-package.cjs`：EXE 与 ZIP 的中文/空格路径冷启动及缓存启动；Windows tar 解压 ZIP；逐文件核对提取结果与兼容 ZIP 的 SHA256；与 1.0.73 核对除明确移除的两个 DLL 外的非 EXE/ASAR 运行资源；核对 ASAR 与最终构建输出一致。
- 源码 ZIP 含逐文件 SHA256 清单；Release 上传 EXE、紧凑 ZIP、直接展开的兼容 ZIP、源码 ZIP 与 SHA256SUMS.txt，核对远端附件大小与 digest 后公开。

上述是本机 Windows 启动器测试，不是所有显卡/系统组合或 Minecraft 游戏启动的全面认证。所有测试只使用自己的进程与临时目录，未更改用户设置或结束用户游戏。

证据：`out/tests-1074-final.log`、`out/build-1074.log`、`out/windows-package-1.0.74.json`、`out/windows-ui-1.0.74-hardware.json`、`out/windows-ui-1.0.74-software.json`、`out/presentation-fixed.json`、`out/release-1.0.74-remote.json`。

## 交付与回退

推荐直接下载 `KAMUCL-1.0.74.exe`。默认 ZIP 内含相同 EXE；`-windows-x64-unpacked.zip` 保留直接展开运行的兼容分发。若出现本次精简特有的图形问题，可换回 v1.0.73 完整 DXC 运行包；如需在源码中回退，撤销裁剪钩子并重新打包完整 Electron 后，图形配置会因 DXC 存在恢复原行为。
