# 启动玻璃动画验证（1.1.5）

## 行为

- Windows 便携包解压前的原生启动画面，以及 Electron 备用启动窗口，均使用 72 片不规则三角形玻璃。碎片带半透明渐变、亮边、轻微旋转和上下漂浮。
- 鼠标 140 个逻辑像素范围内产生排斥，弹簧阻尼控制移动及回漂；最大位移受限。读取系统指针位置，窗口仍不激活、不拦截点击。
- 配置、账户、游戏实例、资源四项真实初始化完成后开始组装，或在主界面已就绪时开始组装。组装从当前实际位置接续，避免被驱散后跳回原位。
- 碎片错开起步，在 1400 ms 内拼成头像；最终绘制完整图像消除三角形接缝。保留原先组装完成后两秒停留。主界面仍必须通过渲染器和首帧双重就绪条件，动画本身不替代初始化。
- 减少动态效果模式显示静态头像，跳过驱散、组装和强制停留。

## 验证结果

- TypeScript 检查及构建通过。
- 完整测试 534/534 通过。覆盖三角网格面积与边界、不同屏幕尺寸、局部驱散、最大位移、移开后回漂、连续组装、精确终点和启动就绪条件。
- `scripts/verify-glass-startup.cjs` 在隔离的真实 Electron 启动窗口中通过：系统指针坐标桥接驱散了约 78 个逻辑像素；真实资源阶段触发组装；提前完成头像仍等待渲染器；揭示主窗口后清理动画窗口。
- 同一验证脚本的 `--reduced` 模式通过：静态头像，无碎片位移，真实就绪后跳过组装和两秒等待。
- `scripts/verify-unified-startup.cjs` 原生动画与 Electron 协调验证通过：首帧约 141 ms，组装及停留约 3471 ms，全程使用同一个原生启动窗口，主界面最终不透明且正常显示。
- `scripts/verify-startup-framerate.cjs` 实测约 59.66 FPS。原生实现缓存小尺寸玻璃纹理，按组装透明度更新纹理，避免每帧进行高成本的旋转透明混合。
- 打包后的主界面在硬件和软件渲染模式均通过验证，覆盖首页、头像预览、图片、IPC、原生模块和扫描线程。

原生离屏预览命令：`out/main/StartupFeedback.exe --render out/glass-preview-1.1.5`。输出漂浮、指针驱散、组装中、完整头像的 PNG，以及被驱散距离。所有测试使用独立目录，没有关闭用户游戏。
