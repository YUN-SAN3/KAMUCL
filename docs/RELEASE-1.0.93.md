# KAMUCL 1.0.93

升级首页「参与测试及创作者」名单动效：每个名字开始浮现时就立即独立飘动，无需等待其他名字显示完毕。

- 名字按顺序以 90 毫秒间隔浮现，出发位置错落分散，取消动态模式下整齐排队后统一出发的效果。
- 每个名字具有独立速度和舒缓的弧线变化，保留相互避让与窗口边界保护。
- 胶囊采用柔和的主题渐变和更轻的描边；保留全部 20 位名单、鼠标移开收起、键盘与减少动态效果支持。

已验证第一个名字在后续名字尚未显示时持续移动，以及独立飘动、快速移入移出、窄窗口边界、点击穿透、静态辅助模式和页面卸载清理。相关测试、类型检查、生产构建和 Windows EXE / ZIP 启动及 SHA256 校验通过。
