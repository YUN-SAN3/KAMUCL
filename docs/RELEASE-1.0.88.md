# KAMUCL 1.0.88

- 录像页默认汇总所有已绑定游戏文件夹中的 ReplayMod / Flashback 录像，包括各实例、共享目录及收藏；无需切换当前游戏文件夹。可按绑定文件夹、录像格式、位置或名称筛选，继续支持收集、导出、复制到实例、回收站与原生拖出。
- 已安装版本默认显示全部绑定目录的版本总数和列表，支持选择某个文件夹或“只看当前文件夹”，筛选不改变新版本的安装目标。
- 每个版本以独立的信息行显示所属游戏文件夹路径，标签与操作区另行排列；上方明确标注新版本安装位置，“添加文件夹”改为“添加新的绑定游戏文件夹”。可用按钮统一提供悬停高亮与键盘焦点反馈。
- 不同目录中的同名实例使用目录与版本 ID 定位，管理菜单、图标、缩略图、Java、窗口设置、隔离、重试与收藏分别作用于目标目录。重命名时只迁移所属目录的服务器绑定，避免修改其他目录的同名实例。
- 导入与“收集到当前文件夹收藏”仍保存至当前游戏文件夹的 `recordings`，界面明确显示目标路径；浏览汇总不会移动或自动复制原录像。任务固定提交时的目标，解除绑定后拒绝继续操作该目录的旧列表项。

验证：484 项回归测试全部通过；TypeScript、涉及的 Vue 页面类型检查、许可证检查与生产构建通过；独立配置下验证两个绑定目录、同名实例、列表筛选不改变安装位置、录像跨目录收集/提取/复制、回收站、原文件保留及拖出调用参数。Windows 便携 EXE / ZIP 启动、构建内容及 SHA256 在发布前核验。

可在完成 Windows 打包后运行 `node scripts/verify-bound-folders.cjs` 重复执行独立目录的界面与文件操作验证。

本次仅交付 Windows 版本，不导出 macOS 安装包。原生拖出的验证覆盖调用与文件参数，未将系统文件管理器的实际落盘标为已验证。
