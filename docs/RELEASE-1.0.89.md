# KAMUCL 1.0.89

- 去掉侧边类目气泡自身的细边框和按钮悬停外圈，保留柔和背景高亮及左侧滑动指示条。键盘操作仍有可见焦点提示。
- 顶栏增加小字：**尝试打造一个方便UP主高频使用的启动器**。鼠标靠近时，附近文字沿远离指针的方向轻轻散开，移开后归位；UP 使用主题色强调。
- 小字随顶栏可用空间缩放，不遮挡下载、通知及窗口按钮。文字区域支持双击最大化/还原，周围空白继续拖动窗口。
- 动效只在鼠标移动时调度绘制，空闲时没有持续动画循环；离开、切换窗口可见性、调整尺寸和进入编辑模式时复位。系统启用减少动态效果时显示静态文字。

验证：484 项回归测试、TypeScript、涉及组件的 Vue 类型检查、许可证检查及生产构建通过。Windows 便携 EXE/ZIP、逐字避让与归位、减少动态效果、边框移除及窄窗口布局在发布前核验。
