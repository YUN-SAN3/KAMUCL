# KAMUCL 1.0.95

游戏版本页以已安装实例为中心：压缩目录管理区域，减少每行常驻操作，让名称、版本、所属目录和启动入口更容易找到。

- 新版本安装位置保留独立工具栏；添加绑定、刷新、打开、重命名、设为默认与解除绑定收进“管理文件夹”。
- 显示范围独立选择全部、当前或指定目录，切换筛选不会改变安装位置；增加实例搜索，目录数与实例数分别标注。
- 实例行保留名称、Minecraft / Loader 版本、所属目录、隔离状态与最近游玩。常驻“管理 / 启动 / 更多”；完整 ID、路径、资源入口、设置、隔离开关和删除确认仍可访问。
- 普通启动按钮采用中性背景，悬停或键盘聚焦时才用主题色强调；列表使用稳定的主题中性承载层与轻分隔线。长名称最多两行，聚焦可展开完整名称。
- 修复服务器收藏星标与选中边框拥挤的问题；资源导航删除重复圆点并记住手动展开状态。
- 用户提供的图片加入首页默认启动卡轮播；自定义图片设置保持原有优先级。

保留启动、下载、扫描、删除与隔离等主进程业务逻辑，本轮不修改主进程代码，不引入新依赖。Windows x64 交付，不生成 Mac 包。

验证：生产构建、现有自动测试、实际 Electron 窗口中的深浅主题、宽窄窗口、100% / 125% / 150% UI 缩放、真实临时目录扫描与筛选、实例管理、删除确认及收藏交互。空列表、失败与启动中状态通过隔离测试进程注入，未启动真实 Minecraft。不同物理 DPI 显示器之间拖动未实测。完整 Vue 类型检查的既有诊断与修改前相同，本轮未扩大范围处理这些历史问题。
