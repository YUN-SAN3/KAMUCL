# 1.0.82 — 版本删除与樱花隧道状态

2026-09-16 20:29

- 版本删除使用操作系统回收站，不再逐项递归删除后因 EPERM 留下缺少版本描述的目录。失败不回退到永久删除，错误提示包含实际目录及占用、权限检查建议。
- 首页与版本列表明确传递游戏文件夹；删除前检查路径边界、目录链接、目录变化和游戏占用，残留安装也使用同一入口。界面明确说明回收站行为。
- 樱花日志支持“隧道启动成功”“隧道启动失败”、认证失败，以及 frp-hub.com 和运营商域名。通用 IP:端口提示中的地址优先于运营商地址；打印地址本身不再误判为连接成功。
- 每条输出流独立进行 UTF-8 解码，处理分片中文和无换行尾部；每个隧道的状态与地址独立推送。

验证：470 项自动化测试、TypeScript、许可检查及生产构建通过。实际 Windows 成品使用独立测试目录，将带只读属性、中文名称和存档的版本目录移入回收站；另一游戏目录中的同名实例保持完整，越界请求被拒绝。没有删除用户截图中的目录，也没有停止用户游戏或隧道。

截图中的用户目录只读检查可访问，未发现根目录链接或显式拒绝 ACL；无法仅凭旧 EPERM 文本确定当时的占用者，因此不宣称已经解除某个外部程序的占用。系统回收站不支持的磁盘或仍被独占的目录会明确报告失败。

原生回收站接口依据：https://www.electronjs.org/docs/latest/api/shell#shelltrashitempath
