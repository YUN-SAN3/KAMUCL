# KAMUCL 1.1.12 验收范围

本轮修复整合包下载文件名和默认下载位置，发布范围为 Windows x64 与 macOS ARM64。Intel Mac、Linux 和原生鸿蒙不生成本轮成品；此前 1.1.11 的完整多平台验收结论保持原样。

默认下载位置入口为「设置 → 启动器设置 → 下载 → 默认下载位置」，游戏版本页显示相同位置。更改位置同时选择新版本与共享依赖、素材和自动下载 Java 的目标，原有游戏文件夹、实例和存档不移动。已接受的任务冻结安装与共享目录；导入可显式指定目标。系统临时目录可能仍用于压缩包缓存，界面明确说明。

下载文件名只规范本地名称，服务器地址、显示名称、大小及哈希不变。保留中文、空格、§ 和扩展名；拒绝目录穿越；Windows 保留名、非法字符和超长名称产生兼容名称。每个整合包任务有独立临时目录，失败、取消和完成只清理本任务文件。

## 必测行为

- 原样例 `Yet Another Bingo: Ultimate-2.14.0.mrpack` 从原 Modrinth 地址实际下载，核对 22843 字节和 SHA1；只探测清单时不宣称已下载全部模组或启动游戏。
- 合成整合包及普通资源通过真实下载器写入文件系统，覆盖并发、取消、下载错误、哈希错误、坏清单、成功和取消清理。
- C 盘旧目录改为 D 盘私有测试目录后，新实例、依赖、素材及运行时路径采用新位置。Windows 使用实际不同磁盘；Mac 使用原生临时目录，不将模拟盘名冒称不同磁盘。
- 下载中途再次改默认位置时，任务完成于接受时的目录，最新设置不被旧任务改回；现有实例仍在原目录。
- 注册目录选择、更改失败、键盘/焦点、重试、重启持久化及游戏版本页导航；实际系统文件选择框若没有完成操作，单独标注不覆盖。
- 深色、浅色、默认黑紫及自定义主题，960×620 最小窗口与 125% 缩放，真实坐标操作及原始截图。
- Windows 便携 EXE、紧凑 ZIP、直接解压 ZIP，Mac 原生 ARM64 APP/DMG：干净启动、版本、应用归档、签名和摘要核对。

## 验证入口

`npm test`、`npx tsc --noEmit`、`npm run license:check`、`npm run build`。专用成品验证：

```text
node scripts/verify-windows-package.cjs
node scripts/verify-download-location-112.cjs <Windows-EXE或Mac.app路径> <x64或arm64> <portable或app或dmg>
node scripts/verify-mac-job.cjs download-location arm64 app
node scripts/verify-mac-job.cjs download-location arm64 dmg
```

独立子 agent 依据本轮最终真实操作、截图和文件系统证据，对合理性、功能性、外观分别评分；每项至少 8.5/10 且无关键缺陷才能发布。夹具验证、真实服务验证及未覆盖项分开记录。不以本次两项修复的评分替代历史完整平台评分。

最终执行记录、评分、附件 SHA256 和公开发布身份以该版本交付记录为准。用户图片、收藏、人物计数、设置和未提交文件保留；个人包、存档、账号、密钥及 `pelican-bicycle.html` 不进入源码和成品。
