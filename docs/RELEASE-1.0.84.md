# KAMUCL 1.0.84

2026-09-16 21:44（本地时间）

- 换肤及首页刷新皮肤成功后，已显示头像立即重新读取；Microsoft 账户显示四色方块图标。
- 删除窄窗口样式给整个界面增加的 8 像素外边距，原生窗口材质、缩放、最大化逻辑保持原有行为。大窗口显示 8 个最近实例，普通窗口显示 4 个。
- 游戏版本只保留文件夹下拉选择；删除重复扫描统计但保留错误提示。“再安装”改为“再次安装”。
- 资源包和光影控件排在标题下方；默认配置页居中并增加 24 像素标题间距；社区“选择版本”按文字基线对齐。
- 下载面板删除重复的同步准备说明，保留总进度、速度、子任务与失败信息。默认多文件并发为 16，用户自定义并发和限速继续生效；HTTP 429 / 带 Retry-After 的 503 按服务器要求冷却同一来源。并发提升不能保证网络带宽倍增。
- Java 自动选择跳过文件或模块不完整的环境；手动指定环境启动前检查版本、架构、运行时文件、游戏所需模块及模块依赖。下载的运行时验证通过后才发布；验证缓存随实际文件变化失效，不增加首屏全盘检查。

验证：477 项测试、TypeScript 检查、许可检查及生产构建通过。私有配置下实际 Windows 成品验证头像刷新、四色图标、最小窗口无外层留白、8 个最近实例、默认配置间距、资源控件位置和社区文字对齐。打包启动、SHA256 与跨平台产物验证结果由发布流程复核后写入 GitHub Release；不把模拟夹具视为真实账户上传或真实 Minecraft 启动。

Java 校验按版本区分模块布局：Java 22 起 SunEC 已合并到 java.base，不能因 Azul JRE 省略空的 jdk.crypto.ec 兼容模块而误报。依据：[Oracle JDK 22 发行说明](https://www.oracle.com/java/technologies/javase/22-relnote-issues.html#JDK-8308398)。该场景已加入回归测试。
