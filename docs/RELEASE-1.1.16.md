# KAMUCL 1.1.16 — Windows x64

2026-10-06 20:49（香港时间）

- 修复 VoxLink 缺失的四块冗余恢复，加入快速重传、受控退避和有界接收队列，改善丢包与重排时的可靠性。
- 社区模组安装默认选择必要前置，可查看关联项目；取消必要前置会提示并阻止不完整安装，查询失败可重试。
- 从模组页面返回社区保留搜索、条件、结果页和滚动；补充常见中文别名搜索。
- 修复社区游戏版本列表被资源卡片遮挡，支持筛选、键盘选择及视口内定位。
- 设置新增“UI 窗口自适应”，默认关闭；开启后按工作区和内容尺寸调整，保留手动缩放，关闭后恢复。
- 修复生成运行文件的等待原因、Java准备状态与嵌套阶段传播，区分等待前置、检查Java、运行安装器和实际完成。

保留用户设置、图片、收藏、历史计数、旧实例和未提交文件；本批不继续资源占用优化，仅提供Windows x64，Electron仍为44.3.0。

验证：1232项测试中1231通过、0失败、1项Linux专属跳过；类型、许可、生产构建及Windows三包验证。四种主题完成实际坐标、原生键盘、最小窗口、125%缩放、失败恢复和进度组件验收。独立评审七项改动的合理性、功能性、外观均为8.9–9.1/10，已验证范围内无关键缺陷，分项和最终证据见[独立评审](https://github.com/kamubaba-i/KAMUCL/blob/v1.1.16/docs/validation-1.1.16/INDEPENDENT_REVIEW.md)。

附件：便携EXE、紧凑ZIP、展开ZIP、源码、交接包和SHA256SUMS.txt。源码和交接包不含用户账号、凭据、图片、整合包、存档或反馈视频。

验证边界：两平台中文查询取得真实官方元数据；前置GUI、文件事务和进度管线按夹具/故障注入分别记录。VoxLink使用真实本地UDP及官方Java传输对端，通过双向丢包/重排和哈希核对，但尚未完成互联网两机NAT、真实Minecraft与语音验收。原ZIP只有录像，原卡住的整合包未取得，不能宣称所有等待问题均已复现解决。物理1366×768主机、完整模型动效基准和人工听感未覆盖。Windows未做发行者签名；Mac历史失败不纳入本版通过。原始失败、帧时间和详细范围见[验证报告](https://github.com/kamubaba-i/KAMUCL/blob/v1.1.16/docs/validation-1.1.16/README.md)。
