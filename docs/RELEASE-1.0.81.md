# KAMUCL v1.0.81 — 自动更新 Minecraft 版本清单

本轮实测 Mojang 官方清单已包含正式版 26.3，`releaseTime` 为 `2026-09-15T11:23:02+00:00`，中国时区显示 `2026/09/15 19:23`；BMCLAPI 清单当时仍将 26.2 标为最新正式版。原实现按下载源选择第一个可用清单，且缓存一小时、进入页面后不再自动刷新，导致镜像同步延迟时遗漏新版本。

- 官方 v2 清单与 BMCLAPI 清单并行核对，同 ID 优先官方信息，合并后按 `releaseTime` 倒序排列。镜像延迟不再遮蔽官方新版本。下载文件继续沿用玩家选择的下载源。
- 元数据请求使用 Electron 系统网络通道，继承系统代理和证书设置；独立八秒超时，单个来源失败不阻断另一个。
- 升级时旧的一小时缓存立即重新验证；新缓存有效期五分钟，手动刷新绕过缓存。缓存采用临时文件提交，网络失败时保留已有数据，取消不会被缓存回退吞掉。
- 进入游戏版本页立即检查，页面可见时每五分钟检查；离开窗口一分钟后返回也会检查。请求期间不重叠刷新，退出页面移除事件和定时器。
- 显示最新正式版卡片与安装入口；卡片和列表均显示本地时区的年月日、小时及分钟，并注明本地时间及最近检查时间。官方不可用时明确提示镜像/缓存降级，不清空旧列表。

验证：466 项自动化测试通过，含镜像先返回旧清单、官方新版本合并、旧缓存迁移、缓存有效期、强制刷新、错误数据与离线回退、取消和时间格式；类型检查、许可检查及生产构建通过。

使用独立配置预置“最新正式版 26.2”的刚写入旧缓存，启动生产构建页面后自动得到 26.3，最新卡片及列表首行时间均为 `2026/09/15 19:23`；缓存升级为新格式，安装入口和 880px 窄窗口布局验证通过。未安装测试游戏，未修改用户游戏目录。
