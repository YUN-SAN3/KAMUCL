# KAMUCL 1.0.87

- 录像页跟随当前选择的 Minecraft 游戏文件夹：自动读取该目录内所有已安装实例及共享目录的 ReplayMod / Flashback 录像，收藏目录为该游戏文件夹下的 `recordings`。切换游戏文件夹同步切换列表和收藏目标，原录像保持原位。
- 返回录像页、窗口重新获得焦点及页面停留时自动刷新；多实例共用录像目录只显示一次。收集、导入等后台任务固定提交时的目录。旧版启动器数据目录中的收藏保留，可通过导入录像加入当前收藏。
- 按住录像名称、模组/资源包/光影文件名称或图标，可发起系统原生拖出；勾选多个录像或模组可批量拖出，每次最多 1000 项。主进程校验目录范围、文件变化和链接，失败显示提示。
- 下载游戏版本时，选中的 ReplayMod / Flashback 没有兼容版本会显示红色边框、警示符号和加粗提示；仍支持选择兼容模组的具体版本，未选有效版本时不能开始安装。

验证：483 项回归测试通过；同步拖出路径调整后相关测试再次通过。TypeScript、录像/安装弹窗的 Vue 类型检查、许可证检查和生产构建通过。完整 Vue 类型检查仍有既有的联机、模组管理及设置组件问题，本批未将其标为通过。

使用独立测试配置验证了当前根目录隔离、同名实例定位、收集/复制/导出/回收站、原文件保留、批量拖出参数及三类资源文件的原生拖出调用、两种录像模组的无兼容提示和窄窗口布局。Windows EXE / ZIP 的启动和 SHA256 在发布前核验。

原生拖出验证边界：已通过真实鼠标触发原生拖放调用和主进程文件参数校验；当前电脑自动化工具禁止跨窗口输入，未完成文件资源管理器落盘及 macOS Finder 拖出实测。回拖到同一 Electron 应用不是外部拖出的有效验收方式。
