# KAMUCL v1.0.80 — CurseForge 整合包文件补全

《元素觉醒 1.4.6》的清单包含 252 个 CurseForge 文件，使用 Minecraft 1.20.1 / Forge 47.4.22。首个错误 `1661637/8695500` 对应 `whisperingstatusbar-1.3.jar`：API 没有自动下载地址，但压缩包 `overrides/mods` 内已经包含大小和 SHA1 完全一致的文件。原导入器在检查包内副本之前就拒绝了空下载地址。

本轮调整：

- 将文件身份解析与下载地址可用性分开；按文件大小及 SHA1 校验包内直接模组，允许改名及禁用文件，排除加载器的嵌套缓存、符号链接和大小写冲突。
- 镜像信息过期时核对另一配置来源；没有自动下载地址时，查询作者在 Modrinth 发布的同字节文件，仅接受 SHA1、大小一致且来自官方 CDN 的文件。
- 仍无自动来源时，在下载中心列出文件并提供对应 CurseForge 页面、多选补充、拒收错误版本及补充后继续安装。环境与其他文件继续并行，不跳过清单文件，也不猜测可下载地址。
- 补充文件先复制到临时文件并校验，再写入缓存；主进程冻结任务缓存目录，切换默认文件夹不改变正在补充的目标。失败或取消回滚实例，已校验缓存可以复用。

实际附件核对：1 个文件从包内复用，7 个可从 Modrinth 取得完全相同文件，1 个仅镜像信息过期而官方地址有效，余下 5 个需从作者的网站下载。受限文件采用用户主动补充流程；测试从官方文件页面取得的 5 个文件仅作本地验收，不随启动器或公开 Release 分发。

验证：460 项自动化测试、类型检查、许可检查和生产构建通过；新增针对错误哈希、改名/禁用副本、嵌套缓存排除、来源身份不匹配、取消回滚、缓存复用和切换默认目录的覆盖。

完整附件在独立配置与游戏目录使用真实下载、真实 Forge 安装器完成导入，约 350 秒；252 个清单文件的大小/SHA1 全部核对成功，最终直接模组 278 个，8,735 个 overrides 文件逐字节一致，源 ZIP SHA256 前后不变。该时间包含运行环境下载、安装及最终文件核对，不包含预先从作者网页取得 5 个补充文件的时间，也不保证其他网络上的速度。验收使用生产渲染页面及真实导入 IPC；仅系统文件选择器在专用测试主进程中注入这 5 个已下载文件，后续复制、哈希校验和缓存提交均使用正式实现。
