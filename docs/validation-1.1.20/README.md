## 夹具与故障注入

localhost/PAC 探针分别覆盖限流、活动等待预算、备用源、暂停、取消、模块晚到和事务失败。旧 Forge 合成夹具覆盖坐标、清单校验、内嵌本体、官方修复 URL、哈希、路径链接拒绝、提交和回滚。正式官方 installer/universal 另外核对真实完整字节；合成载荷不执行 Java。

社区合成元数据与非可运行实例只用于界面状态。真实目标选择不会改变首页实例或浏览条件；编译后的实际 Vue handler 另验证同名不同目录的精确 IPC 目标。GUI 没有调用模组安装 IPC，不把占位实例当作可运行游戏。
