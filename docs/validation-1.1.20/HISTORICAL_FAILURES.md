# 1.1.20 原始失败记录与证据范围

本页保留本批候选与最终成品的历史。失败后的修复必须重新构建、重新验证；旧候选成功项目不能替代最终成品。原始日志、截图及帧时间保留在独立测试目录，用户整合包和用户数据不进入公开源码。

## 已确认的产品问题

- Forge 1.7.10 的请求坐标缺少官方 Minecraft 后缀，原地址返回 404。已通过实际官方 Maven 元数据识别正确分支；现代版本地址保持原流程。
- 实际官方旧 Forge 安装器拒绝 `--installClient`，报 `UnrecognizedOptionException`。新的声明式安装流程校验内嵌 universal、依赖和配置，保留现代安装器 CLI。原始整合包最终安装结果另列，不把合成测试当成真实导入。
- 系统代理/PAC 和模块加载的异步等待存在暂停、取消边界；受控探针复现了暂停后仍派发的请求。修复实际派发门控及派生任务信号，保留暂停排除超时。受控 localhost/PAC 故障注入不是用户网络问题的确定根因。
- 单文件长时间限流可反复等待。现在保留实际 Retry-After，并使用活动等待预算；切换既有可信来源或明确失败，不把长等待静默缩短为正常通过。
- 社区合并检索曾把计数或一平台数据失败当成健康结果。修复每查询的响应顺序、计数失效及可用来源分页；旧响应不能覆盖新查询，失败会显示说明并允许重试。
- 社区下载目标选择实际调用已移除的函数。修复为明确绑定目标实例及其目录，保持当前启动器选择和浏览条件不变。Mac 实际界面发现该问题，Windows 也受同一代码影响。
- 旧 Forge 内嵌本体只有本地路径而没有可修复来源。实际官方 universal 完整字节与 installer 内嵌内容一致；生成配置保留准确 URL、SHA1、大小及原本无 classifier 的缓存路径。删除、损坏后的补下载另有专项证据。
- 原始旧包已安装成功后，独立复核发现四个 Mojang 仅包含 native classifiers 的库被误投影为普通 JAR，缺失可靠 URL 导致 JVM 创建前失败。修复只在没有 classifiers 的旧元数据中使用 Maven 普通库推导，保留明确 artifact 和真正缺失项的拒绝规则。修复前真实配置为 52 项、包含 4 个伪造 JAR；修复后实际 48 项全部有效，4 个原生库 SHA1/大小通过。26 项启动/旧 Forge 专项及随后 1,450 项全量通过，实际 Java 8 进程与 LWJGL 窗口另有有限冒烟证据。旧 596d Windows、b77 Mac 成品均被此次公共产品修复取代，不作为最终成品。

## Mac 原生覆盖仍需明确记录

macOS ARM64 云端使用真实原生进程和桌面窗口，不能作为实体用户机器、macOS 13 或所有 GPU 的替代。此前 1.20.1 游戏线程停在 GLFW 窗口创建及错误消息框；动态库和 Java 架构正确，旧轮次未取得原错误文字的记录仍保留。b77 的原始全桌面图现在已确认错误为 `GLFW error 65545: NSGL: Failed to find a suitable pixel format.`，只读 AXWindows 同时报 -25204，不能把它说成权限为 false。该新增像素证据不证明唯一硬件根因或启动器完全无问题；需要同系统原生像素格式能力观测。26.2 成功进入世界不能代替 1.20.1 失败用例。

最终报告必须记录实际原始帧时间；低于门槛的采集不改为通过，未完成人工听感仍列未覆盖。Windows 发行者签名、Mac Developer ID 签名及公证不能用本地 ad-hoc 校验冒称完成。
