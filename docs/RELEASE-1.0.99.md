# KAMUCL 1.0.99

2026-09-21 22

本次统一主要页面的视觉与交互，保留 Minecraft 插画、玻璃外壳、皮肤预览和现有主题、业务功能。

- 列表、表单和弹窗采用稳定的主题内容底色，统一文字层级、按钮尺寸与窄窗口布局。
- 设置新增外观、游戏与启动、下载、功能、关于与更新分类；支持按名称和关键词搜索并直接定位设置。
- 首页突出实例与启动状态，运行中可再次启动；最近游戏自适应排列，贡献者动画限制在卡片内。
- 模组启用开关仍可直接操作，锁定、版本、删除收进更多菜单；资源包、光影、录像及社区的单页列表不再显示无效翻页。
- 刷新保留已有内容并标记状态，旧筛选结果暂停操作；过期请求不得覆盖新结果，错误与空结果分别提示。
- 皮肤预览、信息、披风与历史按内容布局；MOD 面板和其他空状态提供具体下一步。
- 增加减少动态效果设置并遵循系统偏好；隐藏窗口暂停装饰动画，统一过渡；同类通知合并，补齐弹窗键盘焦点和关闭行为。

验证覆盖全部 13 个主要页面、深色/浅色/自定义主题、最小与常用窗口及最大化、100%/125%/150% 应用缩放、设置定位、快速筛选竞争、失败重试、长名称、运行中状态和弹窗键盘操作。使用独立配置测试，没有结束用户的游戏进程。

缩放测试使用 Electron 应用缩放，未修改 Windows 全局 DPI。网络失败、运行中及账号状态通过隔离测试响应验证交互；本次未重新执行所有整合包全量安装或真实联机游玩。

Windows 便携 EXE 可直接运行；ZIP 请先解压。展开式 ZIP 是不依赖自解压包装的备用包。附源码和 SHA256SUMS.txt。本批不提供 macOS 包。
