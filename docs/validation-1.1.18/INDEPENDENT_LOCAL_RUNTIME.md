## 被审查的生产行为

审查代码包含 `src/main/core/offlineSkinStore.ts`、`skins.ts`、`offlineSkinLaunch.ts`、`launch.ts`、`launchPreparation.ts`、`offline-skin-agent/src/cn/kamucl/skin/OfflineSkinAgent.java`，以及 `src/renderer/src/views/SkinsView.vue` 与 `components/SkinEditor.vue`。

- PNG 经过真实解码、尺寸及内容校验后进入账号范围的存储。应用失败不会生成成功的内存选择；历史、当前选择和启动快照互相区分。异步文件读取与解码保留发起账号，账号 B 不会接收账号 A 的晚到应用结果。
- 启动准备复制账号信息并固定 PNG 字节及模型，使用哈希检测已经变化的本地文件。取消慢读取、共享 injector 下载或 RSA 生成时，当前启动及时结束等待；晚到结果不会继续创建本次启动的 session、端口或游戏进程。
- JVM provider 和 authlib 注入器随游戏启动。provider 在游戏 JVM 内持有 PNG 与签名数据，读取后删除临时 properties；后续请求不需要启动器的存储文件或 HTTP 服务继续存在。
- 本地接口绑定 loopback、使用每次启动的随机路径，并限制 Host、路由、请求长度及自身账号。签名与纹理配置匹配；任意账号、路径穿越和无效请求不获得皮肤文件，服务器 join 返回拒绝。此功能没有把离线账号转换成官方联网身份。
- 启动准备失败会排空并行准备并清理未交付的本地资源。成功交付后的清理由游戏结束触发。日志中的本地 agent 参数及签名元数据经过隐藏处理。
- 先前审查复现的闲置 TCP 连接阻塞 reservation 关闭问题已经修正：接受连接后立即销毁。最终套件包含真实连接的回归测试，验证释放端口不会被闲置客户端拖住。

这里的安全边界判断来自代码审查和特定拒绝请求测试，不等同于全面安全渗透测试。

## 准确未覆盖范围

- 完整世界只验证 Windows 26.3/Fabric/Slim；Classic 的真实 provider、编辑及 authlib 测试不能代替 Classic 在每个 Minecraft 世界的截图。
- 没有旧版本、Forge/NeoForge、多种整合包及所有渲染类 MOD 的完整游戏组合验收，也没有其他操作系统的 native provider/游戏验收。
- 未在真实 demo 中关闭启动器、删除历史后再加载皮肤；此生命周期行为由原生 JVM 资源释放测试及代码路径支持。
- 没有联网多人服、其他玩家客户端可见性或正版登录流程的现场证明。本功能文案也未承诺离线皮肤向服务器或其他玩家同步。
- 首次下载与校验、缓存行为有实现及组件测试；本轮实际世界没有严格断网后重启的独立录证。不能以“离线账号”名称推断本轮网络已物理断开。
- 实际世界使用固定纯色 PNG，不覆盖全部复杂透明外层美术、披风、特殊尺寸、动态热更新或长时间游戏。运行中切换皮肤本来就声明为下次启动生效。
- 本轮 GUI 的请求调度延迟是明确标记的测试夹具；未声称复现每一种真实网络时序。视觉评分不等同于完整无障碍、键盘专用或屏幕阅读器验收。

在上述证据边界内，本次离线皮肤功能达到合理性 9.3、功能性 9.2、外观 8.6；评分未扩展到审查者实现的功能，也未把组件测试当作未执行的完整游戏证明。
