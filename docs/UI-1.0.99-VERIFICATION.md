# 1.0.99 UI 验收

本批依据 2026-09-21 录屏和当前代码实施。测试使用独立配置与独立游戏目录；未操作用户游戏进程。业务下载、安装、联机协议和资源文件格式未改动。

## 实施核对

- [x] 公共内容层、表单、弹窗底色使用主题变量，保留外层玻璃与外观工作台配置。
- [x] 标题、正文、辅助说明、按钮尺寸与圆角统一；内容区降低背景饱和度，窄窗换行。
- [x] 首页保留实例名称主标题、插画、账号与皮肤预览；最近实例自适应列数；运行中显示“再次启动”，保留日志入口。
- [x] 贡献者区域不再传送到全窗口，名字动画限制在卡片内部；支持鼠标展开和键盘按钮。
- [x] 版本下载主要强调推荐安装，普通行中性；现有目录绑定、范围筛选、实例更多菜单完整保留。
- [x] 模组开关常驻；锁定、版本切换和删除收进更多操作；多选批量区保留；资源包、光影共用同一组件。
- [x] 模组、资源包、光影、录像、社区刷新保留同上下文内容；旧结果禁用操作并显示状态；新上下文先清除不适用文件。
- [x] 社区异步请求只接受最后一次结果；页面离开作废请求；首次加载使用骨架；失败与无匹配结果分开。
- [x] 录像隐藏单页翻页控件、移除嵌套列表滚动；保留全绑定目录读取、拖出、收藏、提取与调度。
- [x] MOD 面板断开时根据实例/桥接状态给出下一步；服务器初载、空列表、失败分别显示，刷新不清空列表。
- [x] 联机保留三种方式及其全部业务，页面过渡不排队、卡片不悬浮跳位；共享内容层与字号。
- [x] 默认配置分类与页面间距统一，窄窗重排，保留键位/选项/单材质包同步与持久化。
- [x] 皮肤以预览为主，信息、披风、历史按内容高度排列；空历史紧凑；读取失败可重试，旧账号响应不得覆盖新账号。
- [x] 设置五类导航、14 个可定位分组、名称及关键词搜索；分类滚动位置保留；JVM/API Key 按需展开；旧配置兼容。
- [x] 减少动态效果可保存，叠加系统偏好；停止轮播与装饰，保留手动旋转；隐藏窗口/离开页面暂停并清理。
- [x] 弹窗键盘焦点限制、Escape 关闭与焦点恢复；执行中的危险操作不允许误关闭。
- [x] 相同通知合并、同时最多三条；关闭按钮、通知历史和较长失败提示保留；主题/收藏直接反馈。

## 自动与实际界面验证方法

`npm test`、生产构建、许可证检查；`scripts/verify-ui-system.cjs` 启动真实 Electron 或便携 EXE，通过隔离目录与仅测试进程内的 IPC 响应验证：

- 全部 13 个主要页面；深色、浅色与紫色自定义主题。
- 960×620 最小窗口、常用窗口、最大化，以及 100% / 125% / 150% 应用缩放。
- 搜索逐项定位、旧配置、减少动态效果与系统偏好、快速切页。
- 社区慢请求与新请求交错、刷新失败、空搜索、旧数据禁止操作与恢复。
- 长模组名称、直接启用开关、更多操作、单页分页隐藏、删除弹窗焦点与 Escape。
- 游戏运行中状态与贡献者区域边界。

截图保存到 `release/ui-1099-<theme>/`；详细结果写入 `out/ui-1099-<theme>.json`。Windows 原生窗口另使用桌面截图检查真实玻璃叠加效果。

## 实测限制

缩放验证使用 Electron 应用缩放，未更改用户 Windows 全局 DPI。网络失败、运行中、皮肤账户和社区数据使用隔离测试响应，不冒充真实登录/真实联机或游戏完整游玩；本批未重跑所有整合包的全量安装。真实文件管理读取测试包，生产构建中不含模拟响应。
