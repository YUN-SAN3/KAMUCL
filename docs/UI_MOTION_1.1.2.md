# KAMUCL 1.1.2 — 黑紫主题与交互动效验收

本批沿用 1.1.1 界面结构和业务能力，未改动启动、下载引擎、联机协议、模组同步和游戏数据。

## 需求与实现核对

- 默认主题：保留持久化 `transparent` 键，名称改为“默认·黑紫”。使用中性深灰、紫色强调；内容底色稳定，其他预设和自定义配色保持独立。普通紫色主按钮使用较深强调色提高白字对比。
- 全局折叠：设置分组、Java、高级选项、默认配置说明、资源批量结果、录像结果、实例复制范围、三种联机方式中的说明/诊断/日志等原生 details 共用双向高度及透明度过渡。更多菜单保留溢出显示，避免被折叠容器裁切。
- 下拉：公共 SelectMenu（实例、状态、排序等）和 MinecraftVersionPicker 增加进入/离开过渡。保留原键盘导航、Esc、焦点恢复和真实选项数据。
- 子页：联机方式过渡移到条件分支之外，创建进度与三种入口复用原状态；默认游戏选项子页、实例管理标签、VoxLink 创建/加入/大厅切换均有进入反馈。快速切页不等待离场，不累计动画队列。
- 其他展开：目录管理、通知/下载面板、浮动菜单、设置搜索、设置分类、默认配置标签及弹窗补齐淡入。沿用已有正常工作的侧栏、路由、弹窗及皮肤相关动画。
- 焦点与选中：版本搜索只有一个外侧焦点光晕；下拉、版本筛选、默认配置标签的边框/背景/光晕渐变，保留键盘可见焦点。
- 创作者：寄语常显，没有折叠开关；悬停/键盘聚焦自动展开名单，离开自动收起，每个名字从自身出现时开始独立随机轻浮动。保留原文、名单、标题、链接和专属区域限制。
- 游戏版本：每次进入为已安装，不读旧下载标签偏好；进入下载才获取清单；会话缓存五分钟、并发共享、刷新保留真实旧数据，手动刷新可立即重新检查；保留官方/镜像与离线机制。
- 服务器：列表获得更大宽度，收藏独立置于行尾、统一内边距；轻量选中行、版本信息优先可读字段、状态和详情分组；窄窗口为上下结构。
- 减少动态效果：显式设置及系统偏好均有效；窗口隐藏暂停装饰动画。没有新增持续全局观察器或动画定时器。

## 验证方法与范围

- Node 自动测试：清单缓存复用、并发共享、过期、失败保留与恢复；主题兼容性、色板对比，以及既有完整回归。
- 生产构建与许可证检查。
- 独立 Electron 配置/临时游戏目录检查 13 个主要页面、三种联机入口及弹窗；包含黑紫、浅色、自定义主题；窗口 960×620、1280×900/125%、1440×960/150%、980×720/150% 及最大化。
- 实际采样折叠栏打开/关闭、下拉与子页入场中间帧，验证透明度介于 0 和 1；验证 Esc 关闭恢复焦点。
- 验证旧标签偏好不影响已安装默认入口，首次已安装不发清单请求，下载重入只发一次请求，刷新保留内容。
- 复核设置 14 项定位/焦点/滚动恢复、连续筛选、失败/空状态、减少动态效果、长名称、运行状态、多目录录像、名字边界。
- 成品 EXE 与 Windows 解压 ZIP 分别执行中文路径冷/热启动、运行文件与 ASAR 校验；最终成品单独启动检查。

截图与机器验证报告保存在 `release/ui-refinement-*`、`out/ui-refinement-*.json` 和 `out/windows-package-1.1.2.json`。联机状态、账户及清单在隔离测试进程中使用固定输入；未实际加入他人房间、启动或结束用户游戏。本批不是联机连接质量或游戏下载吞吐测试。系统原生下拉框保留平台交互，不注入模拟动画。
