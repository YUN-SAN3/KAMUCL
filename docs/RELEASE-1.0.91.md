# KAMUCL 1.0.91

- 服务器支持点击星标收藏，收藏项优先显示，并保留原来的实例绑定和快速进入方式。
- 服务器启动移除重复的全目录扫描，只检查所选实例；已验证且未变化的文件可在当前进程短期复用校验结果，文件变化后重新校验。
- VoxLink 三个链接入口合并为「相关链接」，弹窗展示上游契约规定的 8 项链接。
- 对照 VoxLink main `721c7fae` 更新信令、分级及反向打洞、TCP 辅助连接、有限重连和 TURN UDP/TCP 兜底。
- 新增 VoxLink 模组同步：房主共享所选实例的必装/全部两档清单，房客可检查并选择下载；验证哈希，不覆盖冲突或禁用文件，下载完成提示关闭游戏后重启。

## 验证与限制

493 项回归测试、TypeScript 检查、相关 Vue 组件检查、许可证检查及生产构建通过。Windows 便携包验证收藏与排序、相关链接、模组同步选择、弹窗关闭、窄窗口和最大化还原；包内内容与 SHA256 校验通过。

96 个文件共 96 MiB 的本机校验基准：首次约 82 毫秒，同一进程内未变化文件再次校验约 3 毫秒。这是文件校验阶段数据，不是游戏总启动时间；游戏自身加载和服务器网络仍会影响进入速度。

VoxLink 已完成协议夹具与本地回环验证，尚未完成双运营商 NAT 与真实 Java 模组跨公网互联验收。逐项适配说明见源码中的 `docs/VOXLINK-INTEGRATION-1.0.91.md`。上游参考仓库保持未修改。

仅交付 Windows x64，本次不生成 Mac 包。沿用现有未签名状态，Windows 可能显示未知发布者提示。
