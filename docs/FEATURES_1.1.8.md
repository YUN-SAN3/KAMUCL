# KAMUCL 1.1.8

## 皮肤编辑

皮肤页标题右侧提供紧凑的绘制入口，未登录也可绘制和保存。编辑器标题和底栏固定，
预览与绘制工具分区排列，正背面、左右侧与部位显示采用统一主题控件。
左键绘制，中键或 Alt+左键旋转，滚轮缩放；旋转不修改皮肤或撤销记录。
按下时锁定操作，取消、失焦、隐藏和切换模型时结束手势。

编辑器关闭、页面导航、原生关窗和退出应用共用关闭意图流程。未保存确认居中显示，
可保存并退出、放弃或继续绘制；Esc 继续绘制。保存取消或失败保留编辑内容。
保存、上传期间冻结绘制并保留关闭请求，操作结束后恢复处理，取消不会留下退出标志。
主进程还会等待编辑器操作及调色偏好写入。自由调色板、图层和账号上传沿用已有能力。

## 顶栏七人互动

七人采用 Minecraft 方块模型和手工重建的像素纹理，身体背向、头部回望玩家。
专用腰部枢轴表现前俯和臀部后移，双脚落地，不修改普通皮肤预览模型。
纹理来源是用户提供的十四张正背面渲染参考，披风移除；不可见像素按服装风格补全，
不能作为原始皮肤逐像素复原。素材生成入口是 scripts/generate-mascot-skins.cjs。

指针轨迹进入人物可见轮廓触发一次拍打，快速横扫按顺序逐人触发，离开后可再次进入。
像素手掌统一拍在完整着装的臀部，手印跟随人物并淡出。原创掌击声和接触共用时间线，
允许重叠、保留静音与音量设置，不使用外部录音素材。
停止移动约 250 毫秒后，人物转向并迈步到新排名，第一名在最左，同分保持稳定。
人物走到静止指针下不计数，走位期间继续接受拍打。
计数继续使用兼容的累计格式和幂等增量保存，关闭前提交待保存数据。
窗口隐藏暂停，关闭释放 WebGL 与音频；减少动态效果仍保留交互、计数和手印反馈。

## 图片与收藏

首页图片设置以统一列表管理七张内置图和用户导入图，支持参与开关、停留时间、
拖动排序和键盘排序。时长输入使用当前主题，整页滚动取代固定高度的嵌套列表。
取消参与不删除文件；导入图删除有独立入口。稳定 ID、主题往返、实例专属图片优先、
单图和零图停止计时以及全关主题底色继续沿用。

本地 MOD 管理页移除收藏界面，已有记录保留。社区提供“找资源／已收藏 MOD”，
支持搜索、来源筛选、排序、批量取消收藏、查看详情和逐个安装。
未知来源显示未关联状态，手动关联经受控接口验证项目类型，关联前不声称可自动安装。
卡片、详情和安装共用收藏状态及写入队列。收藏安装固定使用 Mod 类型，
新建实例的收藏兼容性和依赖解析继续保留，本轮不增加现有实例批量安装。
