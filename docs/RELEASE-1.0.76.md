# v1.0.76 下载修复验证

本轮使用用户本次附上的桌面 `百人雪山（录制包）.zip`，仅读取内嵌 `modpack.mrpack` 的清单与内容，不运行包内其他 EXE。清单为 Minecraft 1.20.1 / Forge 47.4.20，共 73 个联网文件、147,979,888 字节（约 141.1 MiB）。

## 根因及修改

- 原实现把单文件连接数固定为开始时的预算。其他文件结束后，剩余大文件无法实时使用空闲连接。
- 某个慢分片导致整个文件的分片一起取消；最后 CDN Range 返回 404 后会清空分片，重新单路下载整个文件。实测 ReforgedPlayMod 在这一分支跌至约 40–80 KB/s。
- 改为小分片队列，实时读取连接预算；分片独立选择来源、独立重连续传，正常连接继续工作。来源跳转后的地址在本次文件任务内复用，后续分片参考实测速率。
- 保留旧分片布局及已接收字节，改变线程设置不清空兼容缓存。全局并发/限速、暂停取消、完整哈希验证及校验后提交保持有效。
