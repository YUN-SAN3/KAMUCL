## 历史失败与修正

- 旧6408在实际前台、禁用焦点模拟和完整四主题历史下确认重复“录像”图文／图标。颜色控制、仅删除子项transform、仅删除父项transform未完整解决。两项合成声明一同删除的注入实验清晰，随后真正重建4822并无注入复验通过。实验旧classification曾错误声称无注入，汇总明确更正，原始文件保留。
- 早期桌面裁图错误采到其他窗口，判无效并保留摘要；不得用这些图评分，也不公开其他窗口图片。现检查 Windows 实际前台、HWND/PID、物理坐标。
- 早期披风Sharp／浏览器透明像素差异、公开样本联网超时、不存在的账号导航入口、原生／Electron DPI量化恢复比较失败均保留；独立RGBA参照在产品操作前冻结，真实入口和各自原始尺寸分别严格校验。
- 4822披风汇总的Darwin-only inventory字段假设及PID复用检查各失败一轮。修正纯测量工具，以(pid,创建时间)绑定精确自有进程，再从头跑四主题通过；无他人进程信号，无产品／期限／像素断言放宽。
- 初次窗口采集先因QA未绑定共享桥变量失败；下一轮warm capture末实际前台变为不同PID，严格拒绝，原因未知，不推断用户行为或产品因果，强制自有清理不计自然通过。最终同一严格断言的全新三主题完整通过，六次实际自然关闭0/null。
