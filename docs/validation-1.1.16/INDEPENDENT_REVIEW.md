## 源码与功能证据

### VoxLink

审查 `rudp.ts` 的四块 XOR 冗余、可变长度重建、鉴权、保留 ACK 的处理、非法未来 ACK 拒绝、丢包快速重传、Karn RTT、退避上限和关闭时缓冲释放。对旧接收队列保留较大容量，新增下限有界；不是无限队列。现有 TURN/第二通道及无 FEC 对端仍兼容。相关 [36 项测试](evidence/tests/voxlink116-tests-final.log) 全通过，含真实 UDP 丢包、重排、暂停接收及 DATA/冗余同时丢失回退。

最终源码 SHA256 `a2c44fa3be6baf5df31d26c5248329e8e0012d1c29fd6b68c09612c9bd328b00`。[当前 3 MiB 收据](evidence/voxlink/current-3mib.json) 独立核对 SHA256 `4459469270941c02900c7ad87f15273aeb766c7544ad4cf4e806816774aec3f7`，绑定该源码及官方上游原始 Java 传输实现；只有日志接口为桩。双向各 562 次首发 DATA 故障注入、各 561 冗余包，完整回显 3145728 字节、SHA256 `66d9c4643fae10d99c44fa2e99e9b7ab5dd7dfdc5dd487e34d4a2525fab808a9`，12.341 秒，Java 自然退出 0/null。

[1 MiB 基线](evidence/voxlink/baseline-1mib.json) 为 14.038 秒；[当前同条件候选](evidence/voxlink/current-1mib.json) 4.490 秒。双方各 187 次首发丢失、延迟/重排/读端暂停均在收据中明确。该对照证明此受控协议环境下改善，不外推所有 NAT 或真实游戏速度。用户原录像的准确原因、真实服务、跨互联网 NAT、实际 Minecraft 与语音尚未覆盖。

### 社区

审查 `CommunityView`/`communitySession` 的状态快照、请求代次及实际内容滚动容器，路由返回可恢复搜索/来源/类型/版本/加载器/排序/结果页和滚动。新顶栏查询可替换旧会话；离开时中止显示订阅，不保留整页 DOM。

必要前置默认选中；取消必要前置后明确阻止写入，不能下载一个已知缺依赖的根模组然后报告成功。查询失败不等同于无依赖，可重试；项目详情不重复开启安装入口。已有下载哈希、JAR 描述符、必要前置去重、提交复查与回滚继续适用。[21 项社区测试](evidence/tests/community116-tests.log) 全通过，包含真实产品安装事务配合本地 HTTP 合成文件的落盘/缺依赖零下载检查。GUI 安装确认使用私有夹具，不是实际平台文件下载。

中文查询保留 MC/加载器/来源条件、稳定去重、有界查询和真实失败；中文别名只用于 MOD。独立核对 [Modrinth 真实查询](evidence/services/community116-real-modrinth-04517b8b-18cf-42ca-b2ad-d9248e10ca69.json) 与 [CurseForge 真实查询](evidence/services/community116-real-curseforge-da684f9c-8223-44ee-be6d-ecca5d9d0ce3.json)，当前 `community.ts` SHA256 `1b14fcb7b26f9329d248b1a316eaecd731f8690e3eccdd6e43f97e14361738e1`，两中文查询“玉”“物品管理器”均得到实际官方 API HTTP 200 及 Jade/JEI 等项目，过滤条件未丢失。该证据不是两平台 GUI 联网安装或游戏运行证明。

版本选择 Teleport 到固定前景层，位置随视口、滚动和窗口变化，提供 combobox/listbox 语义、筛选、方向键、Enter/Esc/Tab 及焦点状态。最小窗口和 125% 手动缩放下浮层可见，内容卡片不能越层覆盖。

### 自适应与生成进度

自适应按 Electron DIP 和实际内容尺寸计算，未重复乘 DPI；手动缩放独立保存，禁用恢复手动值。默认关闭路径不主动写窗口大小或缩放；最大化/全屏保留原生行为，异步保存失败回退开关。共享控制器与窗口事件测试覆盖真实 EventEmitter 调度和边界注入。[实现者说明及前期独立逻辑审查](evidence/tests/adaptive116-and-installer-independent-review.md) 明确区分模拟工作区与实物显示器。

`ObservedPreparation` 以目录/Java 主版本/架构复用同一准备工作，所有观察者接收最后状态和后续状态，观察者异常不破坏其他安装，失败后不缓存假成功。加载器生成阶段真实等待前置，进入 Java 检查/目录锁/处理器即报告运行或不定进度；嵌套阶段变更立即发布，不依赖下一行输出。[16 项安装测试](evidence/tests/installer116-tests-fixed.log)、[3 项独立观察者复验](evidence/tests/installer116-independent-adaptive-review.log) 和 [Forge 整合包产品管线测试](evidence/tests/installer116-pipeline.log) 全通过。管线使用实际产品解析/调度/提交，Java 就绪和处理器进程为合成夹具；完成必须晚于就绪、进程关闭和配置覆盖提交。未运行用户原整合包进入游戏，不能把所有长期等待归因这一处状态显示。

实际查看了最终 1cd 成品四主题共 68 张原始 PNG（每主题 17 张，含等待前置、Java 检查、处理器运行、生成完成、任务完成、故障注入六张进度图），并抽看每主题原始录屏第 42/150 帧。原件哈希与公开复制映射一致；没有生成效果图代替产品截图。旧 ec0 的截图和观察仅作历史，不沿用为新成品图像证据。

[黑橙](evidence/ui/black-orange/summary.json)、[白蓝](evidence/ui/blue-white/summary.json)、[透明](evidence/ui/transparent/summary.json)、[自定义](evidence/ui/custom/summary.json) 均绑定实际前台 HWND/PID、Electron 44.3.0 x64、坐标输入、截图哈希及原事件；默认关闭、真实开关保存失败、重新加载保持设置、最大化/恢复、禁用恢复手动比例均通过。Ctrl-minus/0 使用精确所属前台窗口的真实 Win32 SendInput，并观察 Electron before-input 事件；不以 CDP 键盘无法触发主进程钩子的旧失败判通过。白蓝在干净紧凑 ZIP、透明在干净展开 ZIP 运行。

实测最小外框 962×623、内容 961×622 DIP，自动适配后内容约 1144×740 CSS。不是声称原生窗口精确 960×620。宿主工作区为 3072×1680 DIP，没有改变用户显示器分辨率；1366×768 对应工作区仅政策单测，缺少物理 1366×768 主机验收。常用 100%/125% 通过；其他缩放不由该证据推断。

最终四主题录屏是约 2.7 秒导航采集、247–250 帧。原始采集均值分别为黑 90.754、蓝 91.810、透明 90.903、自定义 90.853 FPS；最大原始间隔分别为黑 235.654、蓝 232.713、透明 237.188、自定义 225.528 ms。静态页与路由切换包含在内。保留所有原始间隔，不插帧、不调低目标、不用平均 FPS 宣称完整皮肤/彩蛋/游戏动效通过。JPEG 录屏的白蓝透明背景合成为灰底，和原始 PNG 的浅背景有差别；背景材料的桌面最终合成色彩不能只靠这条录屏判断。外观评分以实际 PNG 可见控件为主，录屏仅核对连续布局与导航状态。

## 历史失败及复评边界

- UDP 大负载首次故障注入计数未达原门槛，虽回显正确仍记录失败；调整测试注入器接收缓冲消除自制造额外丢包，原门槛保留，产品缓冲仍有界。不能把旧失败结果改写为成功。
- 早期 Java 收据绑定旧源码哈希。独立评审指出后，记录 [精确注释/换行差异](evidence/tests/voxlink116-attribution-difference.json)，并以当前 a2c 源码重新执行 1 MiB/3 MiB；旧记录仅保留历史资格。
- 初次安装输出观察断言失败和工具问题保留；修复状态传播后相关测试复验通过。`vue-tsc` 临时缓存加载失败不计为 Vue 检查成功，TypeScript/生产构建证据单独核对。
- 首次 GUI 夹具恢复因 Electron 44 注册处理器包装影响身份判定；测试改存原对象并恢复，产品未改。CDP Ctrl 键绕过真实主进程钩子的断言失败，改真实所属窗口键盘输入，同一产品门槛保留。
- 版本列表联网清单长期加载的 UI 测试未通过，随后用合成清单隔离本轮浮层操作；合成通过不能证明原网络请求成功。
- 早期 owned-close 只记录外层子进程，Windows 库存不可用；不得作为整树退出证明。最终采用单独 Windows CIM 原始创建时间与父子归属采样，核对见下，不把旧 owned-close 写成完整树证明。
- 补录进度 UI 前增加严格的 Java→处理器语义阶段传播断言，旧候选失败：外层实际仍显示 Java 检查，未立即显示运行文件生成。旧事件记录与 `installer116-phase-boundary-first.log` 保留，不能把仅有最终成功当成阶段可见性通过。修复让每个子阶段携带可选 `stage`，外层比较其改变，从而嵌套语义转换立即发布；新增字段向后兼容，不影响总进度权重/完成条件。独立源码核对未发现该修复的关键缺陷，`installer116-phase-boundary-fixed.log` 13 项通过；新成品四主题完整复评通过；评审者独立重跑观察者测试 3/3 通过，并看过所有最终进度状态截图。旧 ec0 SHA256 `ec0e8b749c8fc7e42f587fb90cef893786c9accee6c8fc2a118d84dc8a11aabf` 仅作历史，不作为当前资格。

全量原始 [测试输出](evidence/build/test116-final.log) 为 1232 项、1231 通过、0 失败、1 跳过（Linux 更新替换测试，本批 Windows 不适用）。[许可核对](evidence/build/license116-stage-final.log) 通过。打包、公开 Release 和远端提交仍由主任务另行核验，本评审不从 GUI 测试推断发布完成。
