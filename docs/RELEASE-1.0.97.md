# KAMUCL 1.0.97

修复大型整合包下载慢、镜像跳转失败，并让加载器准备与资源下载进一步并行。本次使用 Mechanomania 1.1.12.0 的实际完整安装验证。

- 正确处理系统网络通道中的手动跳转，修复 `Redirect was cancelled`。逐跳校验地址并重新计算认证信息，保留 Range、流式背压、取消和哈希校验。
- 下载立即采用系统配置的代理/PAC 路由，避免逐文件先等待直连失败；没有配置代理时继续直连，不新增第三方代理。
- Forge / NeoForge 安装器及依赖与原版文件同时下载。本体和依赖就绪后即可生成加载器运行文件，声音和材质资源继续下载。失败或取消会等待所有相关写入停止后再回滚。

## 实测

Windows 便携 EXE，16 个共享连接，不限速，BMCLAPI 与官方备用源；新建独立游戏目录和配置，复用本机现有 Java 21，不启动 Minecraft。

| 场景 | 结果 |
| --- | --- |
| 最终 EXE 完整空缓存安装 | 45.4 秒 |
| 其中 195 个模组准备完成 | 8.4 秒（包含清单解析） |
| 保留已校验缓存再次导入新实例 | 8.9 秒 |

独立复核 195 个模组、3,888 个去重资源、客户端和 106 个已安装带哈希依赖；文件大小和 SHA1 全部匹配。NeoForge 安装器正常退出。

本机使用已配置的系统代理。原版 1.0.96 基线在约 230 秒时出现跳转错误并失败，因此没有可用于计算完整安装提速倍数的成功基线。本次数据也不能证明比视频中的 PCL 快两倍：机器、网络和缓存条件不相同。两轮开发构建空缓存测试分别为 68.6 / 69.7 秒，说明网络等待有波动；45.4 秒是最终便携包独立测试结果，并非保证值。

## 理论边界

该包首次安装已确认的下载文件至少 1,254,236,795 字节（还不含安装器及额外处理依赖），其中模组 328,640,421 字节。按视频中约 350 Mbps 计算，线路理想上限为 43.75 MB/s：上述文件纯传输至少 28.7 秒，模组单独至少 7.5 秒。还需考虑连接、磁盘、校验及 Java 处理，不能保证完整空缓存安装低于 20 秒。缓存命中减少的是下载量，不能当作网络速度提升倍数。

507 项自动测试、TypeScript、许可证检查及生产构建通过；另用实际 Electron 网络栈验证跳转、Range、流式读取、取消、HEAD、校验与当前代理配置。完整数据见 [性能记录](performance/download-1.0.97.json)。
