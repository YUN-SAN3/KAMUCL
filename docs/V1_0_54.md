# v1.0.54：外观工作台与模组内容管理

本版将编辑工具移出启动器页面，解决面板覆盖、长图层列表被挤压、缩放坐标偏移以及编辑直接修改正式外观的问题。参考 Modrinth 的内容管理和安装设置交互，以本项目主题和下载能力独立实现。

## 外观

- 顶部操作栏、左侧语义图层、中央实际窗口尺寸预览、右侧属性占独立网格区域。960px 起适配，窄窗口用标签切换图层和属性。画布提供适应/100%，窗口尺寸改变时更新逻辑尺寸。
- 同组已有 flex/grid 容器按 `order` 排序；不改变父容器布局类型。原生块布局可调真实尺寸/内边距，自由模式支持容器内位移、吸附、对齐和层级0–99。
- 普通图层省略装饰包装；双击深入文字。层级和顺序分离，锁定父组件后子组件不能拖动。图层行固定最小高度并独立滚动。
- 数据继续使用 version 1 schema，增加 mode/layer/locked/gap/padding；有效旧 x/y 自动解释为 free。App 编译标识固化，保留旧组件路径。动态列表仍按布局槽位保存，主题不会改变游戏、文件或账号名称。
- `appearance-draft.json` 只保存外观白名单。400ms 合并自动存草稿；正式应用仅合并外观字段，保留编辑期间改变的游戏设置。写入失败留下草稿；草稿不会在重启后自行应用。
- 连续拖拽/缩放/调色合并为一次撤销，50步历史。单字段、组件、页面、全部组件、默认外观都可恢复。
- 编辑时捕获业务点击及拖入；浏览导航仅允许页面/子页导航。系统弹窗隔离于可自定义组件的层级之外。

## 版本选择

完整保留官方版本元数据，按正式、预发布/RC、快照、远古及全部分类并按日期排序；分类不改变已选值。搜索、类别固定，列表独立滚动；方向/Home/End/Enter/Esc，自动避开窗口边缘。网络失败显示重试和手动输入；后端仍验证输入版本与加载器。目标变化后以代次校验丢弃旧兼容检查结果。

## 模组

- 就地搜索文件名和识别名称；启用/禁用/锁定/可更新筛选，名称/时间/大小排序；保留100项分页。
- 页内选择、全选筛选结果，批量设置目标启用状态。任务绑定原目录，逐项结果和失败项选择保留，切换实例清空选择。单次最多10000项，超过明确报错。
- 锁定记录存于 `userData/mod-state/<actual-directory-sha256>.json`，可信项目标识优先，未识别则按SHA1；改名仍保留，目录间隔离。识别到来源时迁移原哈希锁，批量更新排除锁定项。
- 单项版本选择使用主进程保存的30分钟选择令牌和计划令牌；仅接受列表中的、游戏/加载器适配且带HTTPS与SHA1的文件。显示版本说明，检查必要前置；锁定/缺失前置需要明确确认。
- 下载临时文件后重验源文件/列表/运行状态；替换前保留原文件备份，拒绝目标冲突。提交失败恢复；如外部同时修改阻碍恢复，保留备份并报告路径。禁用和锁定状态传递到新文件。
- 社区元数据只能保证声明的适配关系，不能证明任意模组组合能正常运行；必要前置缺失和冲突以可确认警告显示。
