# v1.0.77 多阶段同步下载

整合包导入原先等待游戏本体、公共资源和加载器全部准备完成后才开始下载模组。本轮让整合包文件提前下载到缓存，同时准备运行环境；游戏本体、依赖库与资源文件也分别并行下载。

所有分支共享现有全局连接数与限速，不把每个阶段的线程数累加到网络上。依赖前置条件的加载器安装、实例配置与文件提交仍保持正确顺序。下载并行能减少等待，不能突破线路带宽上限。

## 实测

使用桌面附件 `百人雪山（录制包）.zip` 内的 mrpack：Minecraft 1.20.1 / Forge 47.4.20，73 个联网文件、147,979,888 字节。只读取整合包，不运行附带的其他启动器 EXE。

两次都是本机正式打包程序、独立空游戏目录与缓存、默认 8 个全局连接、国内镜像。计时从本地 ZIP 开始导入到实例完整提交，包含游戏本体、公共资源、加载器和整合包文件。

| 版本 | 完整导入 | 整合包文件阶段 | Forge 安装器下载 |
| --- | ---: | ---: | ---: |
| 1.0.76，串行准备 | 228.847 秒 | 77.033 秒 | 6.278 秒 |
| 1.0.77，并行准备 | 144.129 秒 | 40.515 秒，与运行环境重叠 | 5.670 秒 |

本次完整导入减少 84.718 秒，约 37%。全部 73 个实例文件再次逐个核对大小和 SHA512。并行阶段真实网络请求与生产下载中心分行展示均有验证。结果包含网络时段差异，不能将全部差值归因于并行，也不承诺所有地区或运营商的固定速度。

## 正确性及交互

- 447 项自动化测试通过，包括真实四阶段网络屏障、成功提交、下载失败与取消后无迟到写入、暂停继承、缓存隔离、已有全局限速与断点续传测试。
- 运行环境和整合包分支任一失败，立即取消同组任务，并等待所有写入退出后回滚。经哈希验证的缓存保留供重试，无哈希文件使用本次任务专属暂存目录并清理。
- 只在运行环境准备完毕后复制模组到实例，不建立硬链接。原有覆盖与用户文件恢复顺序保持不变。
- 下载中心分别展示各并行阶段、汇总有效下载速度和总进度。仍有未知安装工作时不猜测整体 ETA；完成前不提前显示 100%。高频安装器输出合并刷新，避免刷屏。
- 类型检查、许可检查与生产构建通过。Windows 便携 EXE、紧凑 ZIP、完整 ZIP、源码及 Mac 双架构包沿用现有构建与发布验证流程。
