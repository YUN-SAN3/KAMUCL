## 共享范围和兼容性

- 复用主题色、内容底色、间距、圆角及动效变量，不将蓝色/白色覆盖到其他主题。
- SelectMenu 增加可选第二行说明，原单行选项与键盘处理兼容。
- 页面原控件 data-ui 标识固定；移动容器时只匹配唯一旧叶节点，歧义时不套用其他控件样式；旧配置不删除。
- 共享 CSS 的焦点、折叠和设置滚动规则回归游戏版本、弹窗及其余页面；页面专属规则限定在自身根类。
- 生产源码没有测试数据。GUI 脚本创建临时中文路径、隔离用户配置，只在测试进程注入确定性响应；不操作用户游戏、账号或真实房间。

## 验证方法与证据

- `npm test`：524 项，包含当前页半选、文件名展示、陶瓦角色判定、旧外观唯一匹配，以及既有下载/启动/联机回归。
- `npm run license:check` 与生产构建。
- `scripts/verify-ui-refinement.cjs`：真实 Electron 界面，覆盖 13 个导航页及 FRP / VoxLink / 陶瓦子页；截图在 `release/ui-refinement-<主题>/`，结果在 `out/ui-refinement-<主题>.json`。
- 窗口：960×620、1280×900 @125%、1440×960 @150%、980×720 @150%、最大化；截图使用实际设备像素，不能直接当成逻辑尺寸。
- 行为：设置 14 处搜索定位/焦点/滚动恢复，快速切页，社区连续筛选/迟到响应/失败重试/无结果，弹窗 Escape 与焦点，游戏运行中再次启动，装饰动画边界和减少动态效果。
- 联机状态采用隔离测试响应，覆盖 FRP 多隧道与密钥收起、陶瓦缺工具/房主/客人；不把界面状态模拟视为公网连接测试。
- Windows 便携验证：原始 EXE 和系统解压 ZIP 的冷/热启动、完整运行文件逐项哈希、ASAR 与当前生产构建一致、成品 GUI 启动。

## 真实限制

- 本次没有更换真实账号皮肤或建立跨公网多人游戏，不声称完成所有账号权限、NAT、运营商及显卡组合实测。
- 对任意用户自定义自由布局无法保证自动迁移后完美排版；唯一控件匹配与原配置保留已验证，重复且歧义的旧标识不会猜测套用。
- 缩放通过实际 Electron 窗口的 UI 缩放完成，并非更改用户 Windows 全局 DPI 设置。
- 本次只提供 Windows 成品，不生成 macOS 包。
