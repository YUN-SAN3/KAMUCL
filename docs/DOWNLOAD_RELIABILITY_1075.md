# 1.0.75 下载修复验证

## 原因与处理

- Forge/NeoForge 安装器原先强制先走官方单连接，整条重试耗尽后才进入国内镜像；现在遵循下载源设置，读取 Maven SHA1 与大小后分段校验下载。
- 分片原先没有启用 HTTP 客户端已有的独立连接选项。现在分片使用独立连接，文件多时限制每文件工作线程，尾部文件重新分配空闲预算；同一文件的分片尺寸保持稳定，以便换源续传。
- CDN 的 Range 请求可能 404，而普通 GET 200。现在回退普通 GET 并校验同一文件，不将该情况直接视为文件被移除。
- CurseForge 文件认证仅在官方 edge 域名发送应用密钥，每次跳转重新判断，不能透传给镜像或其他域名。
- CurseForge 清单解析保留大小、SHA1 和精确文件身份。禁止使用错项目元数据或猜测名称创建下载任务。校验后的整合包缓存不随安装事务失败而丢失。

协议参考：

- [CurseForge 文件下载认证公告](https://blog.curseforge.com/introducing-api-key-authentication-for-curseforge-file-downloads/)
- [CurseForge 文件信息 API](https://docs.curseforge.com/rest-api/#get-mod-file)
- [MCIM 镜像 URL 规则](https://docs.mcimirror.top/)

- 包内 Forge 1.20.1 / 47.4.20 安装器：8,835,110 字节，下载成功。
- 中断测试后复用已校验的 69 个文件，再次下载完成剩余文件，整包校验通过。
- 截图中 reforgedplaymod 文件 SHA1：37b714750d0e5487b488b29ff1e1623e5bb18ed6，最终文件校验通过。
- 自动化覆盖：Maven 元数据与并行连接、Range 404 降级、普通 404 换源、缓存复用、精确身份拒绝、认证跳转隔离，以及现有暂停/取消/限速/哈希失败/断点测试。

没有修改用户的网络、下载线程设置、运行中的游戏或原整合包。
