# KAMUCL 1.0.94

整改 VoxLink 连接流程与界面，修复自动中继互相触发、连接状态残留，以及加入房间后看不到连接地址的问题。

- 按 VoxLink `main` 提交 `924845e` 核对并移植打洞参数、NAT 策略、端口预测、多 socket、PPS 限速及持续重试；删除自造端口扫描和固定总重试预算。每个参数保留上游来源，新增逐值验收。
- TURN 改为连接 20 秒后由玩家主动选择。选择后取消同一玩家的直连任务；中继失败只显示手动重试，不自动重新打洞。
- 按最新契约由服务器注入加入信令，失败后重新加入，不再自行定时发送 `join_request`。
- 创建或加入后自动进入连接进度页；成功突出显示本地地址、复制按钮，以及“进入游戏 → 多人游戏 → 直接连接”指引。阶段变化立即清理旧地址和旧进度。
- 相关链接移到顶部，公共大厅采用卡片布局，连接记录按阶段和等级折叠。无游戏时提示先启动并开放局域网，同时提供手动端口输入。
- 模组同步主进程保持不变，保留按所选实例检查两档模组清单、下载校验及重启提示。

验证包含全量自动测试、相关类型检查、参数逐值比对、本机协议往返、生命周期回归、Windows 便携 EXE/ZIP 启动与 SHA256。页面测试使用独立配置及测试事件，不会替用户创建公开房间。真实跨运营商 NAT 与公网 TURN 仍需实机互联验证。

详见 [对接整改记录](VOXLINK-AUDIT-1.0.94.md)。仅交付 Windows x64，不生成 Mac 包，沿用现有未签名状态。
