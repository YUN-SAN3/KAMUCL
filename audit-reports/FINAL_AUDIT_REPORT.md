## 正式身份与公开致歉

本版第一条内置日志和公开 Release 使用用户批准的致歉原文。自有 Client ID 是公开应用标识，不是 Client Secret；公共客户端不内置秘密。取得 ID、设备码 200 或授权页面显示 KAMUCL，均不足以证明 Xbox/XSTS/Minecraft 全链、重启续期和正版游戏启动已通过。

真实服务历史保留：最初设备码 401 invalid_client/AADSTS70002；随后同一 ID/scope 请求 200；用户确认授权页面为 KAMUCL，但旧代理轮询 NETWORK_ERROR 终止；代理修复后的新请求持续至 DEVICE_CODE_EXPIRED。没有回退第三方 ID，没有将该过期流程记为完整登录成功。

## 待核实及未覆盖

- 公开 Client ID 已切换；完整真实 Microsoft/Xbox/Minecraft 授权、续期及游戏启动仍需测试账号交互结果。
- 素材来源说明不能替代逐素材授权。Minecraft 贴图、用户参考素材及历史衍生资源的证据不足项保留，不能承诺全部商业使用清白。
- 补充运行时源码包含固定 Electron/FFmpeg 源码和配置，不包含完整 Chromium 源码，也没有声称字节一致地重编译官方运行时。
- 依赖补丁后 npm 的受影响条目仍为 14（3 high、11 moderate），不是 14 个独立漏洞；已评估实际使用面和约束，未进行不兼容的框架大版本替换。
- 合成凭据服务不能替代 Windows DPAPI/macOS Keychain 原生检查；生产 renderer 的 IPC 夹具、离屏 GPU 与中性桌面底色不证明真实登录、游戏或原生毛玻璃。
- Mac 旧整机的 Cmd-minus keyUp、GLFW/NSGL 及可辨认游戏画面缺陷/失败记录保留。本版改动专项通过不能替代全平台无差别验收。实际听感、全部动效/FPS 和物理 macOS13 尚未全覆盖。
- Windows 未进行发行者签名；Mac 仅 ad-hoc，没有 Developer ID 签名或公证。
